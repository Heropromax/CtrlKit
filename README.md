# CtrlKit

面向实时控制的轻量 C++20 头文件库，提供数学运算和可组合的离散动态模块。

适用于机器人、飞控、云台、电机等控制程序中的基础信号处理。模块自己保存状态，使用者负责组合、采样周期和调用调度。

## 当前能力

- 固定维度向量：逐元素运算、标量广播、点积、叉积和限幅。
- 数学工具：向量初等函数、幂运算、角度换算。
- 姿态运算：四元数、向量旋转、ZYX 欧拉角转换。
- 动态模块：一阶/二阶低通、积分器、带限幅积分器。
- 动态模块可使用浮点标量或浮点向量，复用同一套实现。

核心采用固定尺寸存储和模板组合，不依赖堆分配、异常或运行期多态。仿真、可视化、调度和完整控制器由外围应用负责。

## 最小示例

```cpp
#include <ctrlkit/dynamic.hpp>

int main()
{
    // 采样周期 1 ms，时间常数 20 ms，三个轴共用滤波系数。
    ctk::Lpf1st<ctk::Vec3f> filter(0.001f, 0.02f);
    const ctk::Vec3f measured{1.0f, 2.0f, 3.0f};
    const auto filtered = filter.step(measured);
    (void)filtered;
}
```

将 `include/` 加入头文件搜索路径，并启用 C++20。库本身无需编译或链接，需要哪个模块就包含对应头文件。

`ctrlkit.hpp` 是基础头文件，**不会包含全部模块**。完整接入与仓库构建步骤见[入门指南](docs/getting-started.md)。

## 项目状态

项目处于 pre-1.0 阶段，公开 API 可能变化。

库本体要求 C++20；当前仓库测试程序使用 C++23 的 `<print>`。非法参数检查尚不完整，调用者需要满足接口前置条件。具体行为见 [API 文档](docs/api.md)，已知缺口见[路线图](docs/roadmap.md)。
