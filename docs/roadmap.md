# 路线图与已知缺口

本文记录当前计划和实现缺口，不是功能承诺。已实现接口见 [API 文档](api.md)，长期边界见[设计说明](design.md)。项目处于 pre-1.0，优先级会随实际使用调整。

## 已从原计划落地

- 标量和向量 saturate 已实现，并有相关测试。
- 带限幅积分器已实现，实际名称为 IntegratorSat，不是原计划中的 IntegratorLimit。
- 向量运行期标量指数 `pow(v, exponent)` 和编译期整数指数 `pow<E>(v)` 已实现。

以上表示接口已经存在，不意味着所有健壮性问题均已解决。

## 优先处理的正确性与可移植性缺口

| 项目 | 当前情况与下一步 |
|---|---|
| 非法参数处理 | dt、tc、fc、zeta、限幅区间尚未统一检查；API 先明确前置条件，后续决定检查或拒绝策略 |
| 非有限值和溢出 | 没有全库 NaN、无穷值或溢出保护；限幅无法修复所有此前产生的错误 |
| 头文件独立性 | dynamic.hpp 使用 std::numeric_limits 但未直接包含 limits，需修复并验证头文件独立包含 |
| 初值一致性 | IntegratorSat 构造保存原始初值，reset 立即限幅；需决定是否统一，当前按 API 如实记录 |
| 工具链验证 | 区分目标支持基线与实际验证记录；测试依赖 C++23 `<print>`，不等于只需 C++20 的库接入要求 |

这些问题属于正确性或维护约束，不纳入可长期容忍的风格偏差。实现策略应兼顾无异常、低开销和可诊断性。

## 功能计划

| 优先级 | 项目 | 范围 |
|---|---|---|
| 较高 | 微分模块 | 补齐常见控制基础积木，先确定滤波、初值和输入语义 |
| 较高 | 常用数学补充 | 按需求加入 abs、sign、min、max、sqrt 等，避免一次扩展为数值全家桶 |
| 较低 | 轴角与四元数转换 | 有实际应用需求后再补 |
| 较低 | 更多滤波器 | 按目标应用评估高阶、带通或带阻等能力 |
| 暂缓 | 定点数支持 | 独立评估数值与类型设计成本 |
| 待需求 | Delay 模块 | 当前没有明确需求，不等同于永久排除 |

## 收敛与待决策事项

- 统一部分模板约束使用 requires 或 static_assert 的策略。
- 如继续将 `pi<T>` 与 `pi_f/pi_d` 视为并存试验，应补充选择依据和退出条件；目前尚未确定。
- 按目标工具链记录 constexpr 实际可用范围；当前 Lpf2nd 构造函数不支持常量求值。
- 按使用反馈评估测试布局和 CMake 库接入方式，当前不将测试程序视为完整发布与安装体系。

## 核心范围之外

完整 PID、轨迹规划、统一采样调度、仿真求解器和功能安全认证不在当前核心范围。可视化、仿真和第三方环境配套属于外围方向，尚未作为本库现有功能提供。
